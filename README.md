# Ruen Bongkot — Royal Thai Kitchen 🪷

A website for **Ruen Bongkot**, an authentic royal Thai restaurant at
750 Central Park Avenue, Scarsdale, NY 10583.

## Features

- Dark, gold-accented "royal Thai" design with lotus motifs
- Animated hero with glowing accents and scroll-reveal sections
- Tabbed menu — Royal Starters, Fan-Favorite Noodles, Regional Specialties
- Lunch special callout (daily 11 AM – 3 PM)
- Reviews, directions, and delivery links (Uber Eats, DoorDash, Seamless)
- Fully responsive with a mobile slide-down navigation

## Running locally

It's a static site — no build step needed. Just run:

```bash
python3 run.py
```

This serves the site at http://localhost:3000 and opens it in your
browser automatically (pass another port as an argument to change it,
e.g. `python3 run.py 8080`). You can also open `index.html` directly.
